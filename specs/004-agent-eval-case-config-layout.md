# Agent Eval 案例配置页布局调整

状态：Implemented  
日期：2026-10-09  
关联：`specs/003-agent-eval-header-editor-ui.md`  
确认记录：2026-10-09 用户回复“实施把”，批准本方案与 spec 003 一起实施。

## 1. 目标与范围

优化用户截图中的案例编辑“配置”标签页，将模型连接、请求头和高级执行设置分组，改善表单密度、标题对齐和响应式布局。配合 spec 003 的共用请求头编辑区一起实施和验证。

仅修改 Web 表单结构与专用 CSS。保留 SDK、请求参数、配置读取/保存、默认与案例覆盖规则、日志行为及执行语义。

## 2. 当前行为与问题

- 案例配置由“环境与执行配置”和默认展开的 details“高级配置：模型、超时与系统提示词”组成。
- 高级配置中 Provider、模型、密钥环境变量、Base URL 均使用整行输入框，与请求头、超时和提示词连续堆叠，分组弱、页面较长。
- `.Box-header` 使用 flex 分散对齐；details 的箭头伪元素与直接文本成为两侧元素，导致截图中箭头靠左、标题靠右。
- appendConfigFields 的 modelOnly 分支缺少模型连接字段专用布局，不能随着实际容器宽度适当并列。
- 默认头与案例覆盖头缺少明确视觉分区。

已阅读开发约定、roadmap、spec 001/003、renderCaseDetail、appendConfigFields 及 Box / Config 样式。

## 3. 视觉与结构方案

### 折叠栏与表单来源

- 保留高级配置的折叠交互及默认展开状态，将标题简化为“模型与高级配置”。
- 箭头和标题放在左侧同一组，标题不再靠右；修复样式限定在本页配置组件，避免影响其他 Box 或折叠区。
- “已载入案例保存的配置”等来源说明显示为轻量辅助文字，保持原有来源语义。

### 高级配置内部

分为有明确间距和轻分隔线的四组：

1. **模型连接**：容器足够宽时 Provider / 模型并排；密钥环境变量保持完整字段，Base URL 占整行，方便阅读长地址。窄容器全部单列。
2. **默认模型请求头**：应用 spec 003 的卡片编辑器，说明这是案例保存的默认连接设置。
3. **案例请求头覆盖**：独立分区，说明“同名请求头覆盖上方默认值；留空继承”。保留两层配置的独立编辑和保存。
4. **高级执行设置**：超时使用适当宽度的输入框，系统提示词使用整行多行文本框，留白与辅助说明统一。

整体内边距、区块间距和字体层级沿用现有 CSS 变量。表单不增加侧边导航、弹窗或新的操作步骤。

### 环境与执行配置

保留完整任务模式下现有工作区、工具范围与最大迭代次数区域，统一标题、内边距和字段间距。单轮模式的隐藏规则保持不变；超时和系统提示词在两种模式中仍可编辑。

### 响应式与复用

- 模型字段使用专用 grid / 容器查询，不依赖整页 viewport 判断案例左侧栏可用空间。
- 输入框 min-width:0，长 URL/模型 ID 不撑开页面；说明文字可自然换行。
- 若调整共用 appendConfigFields 的字段包装，检查设置页和批次表单，确保布局一致、字段只渲染一次。

## 4. 接口、兼容性与异常处理

- 保留 f-provider、f-model、f-keyenv、f-baseurl、f-timeout、f-sysprompt 等控件 ID，已有 readConfig / readDefinition 和校验定位继续工作。
- 不改变 headers 与 headersEnv 数据结构、两层覆盖、配置来源优先级、超时单位或默认值。
- 保存失败和字段错误沿用原逻辑；被隐藏/折叠的错误控件仍能展开定位。
- 输入/判定规则/配置标签切换保留未保存值，案例运行与保存操作保持现有行为。

## 5. 验收标准

1. 真实浏览器检查案例配置页：标题与箭头左对齐，模型字段合理并列，四组清晰，不再形成无分隔的长表单。
2. 在宽页面的窄案例栏和约 360px 移动页面检查布局，无横向溢出；长 URL、空请求头和多条请求头均可操作。
3. 现有案例正确载入 provider/model/keyenv/baseUrl/timeout/systemPrompt 和两层请求头；修改后保存、重新打开与运行配置一致。
4. 切换单轮/完整任务和三个标签页不会丢失输入，环境区域的显示规则保持原样。
5. 全局设置和批次配置共用部分不出现重复字段或样式回归。
6. 请求头/配置相关现有测试、typecheck、Web bundle 构建和 git diff --check 通过；视觉验证结果与限制如实记录。
