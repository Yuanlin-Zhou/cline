# SPEC-045：多轮报告信息层级优化

状态：Implemented / 已实施
日期：2026-11-17
确认记录：用户确认桌面原型并要求“按照这个 UI 先做一版”。本文件记录已批准原型的实现细节，不重复请求批准。

## 目标与现状
当前报告混合文本通过率、最终状态、任务验收和输出一致率，多层折叠和长句难以阅读。按原型改为概览、各轮表现、案例稳定性三级；使用 Ant Design，仅面向桌面。已阅读 AGENTS、内网 roadmap、SPEC-041、repeat-report 服务及详情组件。

## 方案与数据口径
主视图使用当前选择尝试对应的案例逐轮最终状态。总体/每轮通过率为通过执行数 / 计划执行数（案例数 × 轮数），说明分母包含错误、无法判定、取消和待完成。统计不使用旧版文本通过率字段；首次/最新模式切换重置局部筛选和详情。
概览四卡：总体通过率、每轮都通过、通过情况有波动、输出有变化。波动指同案例同时出现通过和失败，错误不冒充失败。单轮或样本不足明确显示暂无法判断，输出少于两次可比较时不展示 0/0。阶段性结果有提示。
各轮表分列展示状态及通过率，可打开该轮案例。案例矩阵展示每轮状态、稳定性、输出版本；支持全部/有波动/每轮通过筛选，点击状态查看执行，查看对比展开该案例逐轮结果、异常和输出版本入口。多轮横向滚动且固定案例列，避免挤压。
详细验收统计、比较口径与原始 JSON 收入底部折叠区；已有导出不变。保留输出变化不等于质量下降的说明。

## 接口、兼容与异常
不修改后端合同、数据库或 SDK；复用 RepeatReport 的 cases.rounds/variants 和现有执行详情接口。空列表、加载失败及重试沿用 DataState；长案例名称最多展示两行并支持悬停查看全文，长错误可滚动。无数据/只有一轮不宣称稳定。比较为逐轮结果及版本分组查看，不增加文本 diff 服务。

## 验收与实施
提取报告组件，实现概览、表格、筛选和详情入口；真实桌面浏览器验证单轮、多轮混合结果、首次/最新、空/错误重试、长内容及截图。运行类型检查、构建和相关浏览器回归，记录实际复核后标记 Implemented。

## 实施与验证（2026-11-17）

- 报告从批次详情提取为独立 React 组件。使用 Ant Design Card/Statistic/Table/Progress/Segmented/Collapse，保留后端合同及导出。
- 主视图从所选尝试的逐轮状态计算通过数、已完成轮数及稳定性，避免原有汇总字段在首次/最新模式下口径不一致。总体通过率分母为计划执行数，旧版文本/验收指标保留在折叠区。
- 类型检查、Vite 生产构建及 Biome 检查通过；既有多轮/重试后端测试 11 项通过。浏览器工作台回归通过，新增报告流程回归通过：单轮提示、三轮 7/9 通过、波动筛选、输出版本、执行详情、轮次详情、首次尝试、阶段性状态、八轮滚动、503 错误/重试及空数据。
- 浏览器使用本地模拟模型生成真实单轮记录；多轮混合状态使用拦截报告接口的确定性测试数据，执行详情仍读取真实记录。未调用外网模型。
- 实际截图已检查：1440px 单轮/三轮/案例对比，1280px 长名称、部分完成、八轮横向滚动、空状态与错误。发现并修复了八轮表格撑开页面问题（Grid 列最小宽度约束）和长名称占用过高问题；多轮表格内部滚动，案例列保持固定。截图保存在 assets/045。
- Vite 保留原有主包大于 500 kB 提示。本次无 SDK/数据库/依赖变更；未提交推送。
