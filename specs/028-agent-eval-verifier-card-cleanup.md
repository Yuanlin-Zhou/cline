# SPEC-028：验证脚本列表卡片对齐与信息精简

状态：Implemented
日期：2026-10-27（北京时间）
基线：`5496267`，已回退 SPEC-027 的整套 UI 修改。
范围：仅验证脚本管理页的列表卡片、说明文案及既有编辑弹窗中的只读版本信息。不恢复整套 UI 改版，不修改其他页面、SDK、API 或存储。

## 1. 目标与当前问题

用户截图显示同排卡片顶部错位、卡片内容重复且留白过大。

已对照 SPEC-019、内网 roadmap、verifier-manager.ts 与 style.css：

- 卡片使用 `.Box`，全局 `.Box + .Box { margin-top: 16px; }` 意外叠加到网格第二个及之后的卡片，导致第一张卡片比其他卡片高出 16px，行间距也被叠加。
- 列表每张上传卡片重复展示 Python、内容版本 hash 和“包含已归档案例”；配置注册卡片重复长段只读说明，并将未识别的运行环境统一称为“其他运行环境”。
- 卡片没有独立的标题、次要信息和底部操作布局，名称/文件名长度变化时操作位置不稳定。

目标是修复错位，保持现有卡片网格风格，让用户优先看到脚本名称、必要文件名、引用数量和操作。

## 2. 具体呈现

### 2.1 上传的 Python 脚本

默认只显示：

```text
read_files 调用格式
verify_read_files.py

未引用                 查看 / 编辑   下载   删除
```

有引用时以“1 个案例引用”“6 个案例引用”等呈现。引用数仍来自现有接口，不改计数口径。页面列表数量旁统一提示“引用数包含已归档案例”，不再逐卡重复括号说明。

不在每张卡片重复 Python 和版本 hash。版本信息放到已有查看/编辑弹窗的“脚本信息”折叠区，只读展示文件名、运行环境与完整版本值，不修改源码/保存令牌或增加列表预取请求。

仍保留查看/编辑、下载和删除三个直接按钮；不增加更多菜单，不改变删除确认和引用检查。删除入口仍可打开确认框查看被引用情况。

### 2.2 配置注册和兼容脚本

配置注册卡片默认只显示名称和“配置注册 · 只读”标识；真实存在文件名时保留文件名。不再显示“配置注册程序 · 其他运行环境 · 1”这种信息串。

配置注册的来源、实际运行环境与版本放在卡片内“详细信息”折叠区；未知环境写“未声明”，不猜测语言。维护方式在页面统一提示一次：“配置注册的验证器由服务端维护，此处只读。”

上传的非 Python 兼容脚本维持只读和原有使用方式，以“兼容脚本 · 只读”标识及折叠说明表达，不新增编辑或删除入口。

## 3. 布局与样式

- 使用验证脚本管理页专用卡片类，仅在该页覆盖卡片 `margin: 0; min-width: 0`，网格间距统一由 gap 控制，不改全局 `.Box + .Box`。
- 同排卡片顶部和底部对齐；卡片纵向布局，上传卡片操作区置底，对齐相邻操作行。
- 不设固定高卡片或大块占位；采用紧凑 padding、12–16px 内间距，降低目前大面积空白。
- 长名称和文件名允许换行、可查看完整文字，不挤出边框；按钮在窄卡片上自然换行。手机单列，不产生整页横向溢出。
- 沿用现有字体、颜色、按钮和圆角，不新增字体、依赖、动画或全站视觉规范。

## 4. 数据、兼容与异常处理

无 API、数据库或数据迁移变化，SQLite/MongoDB 继续使用同一列表及详情接口。不改变脚本来源判定、引用数、冻结快照、版本校验和保存/删除保护。

搜索仍匹配名称和文件名。上传、下载、编辑、刷新、语法错误保留、未保存退出确认保持原行为。加载失败保留既有列表与错误反馈；空列表与搜索无匹配仍明确展示。折叠信息可以通过键盘打开，不使用 hover 作为唯一入口。
