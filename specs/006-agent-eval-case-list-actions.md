## 目标与当前行为

当前每行显示运行、查看、复制、移动、归档、删除六个按钮，操作列拥挤。按用户要求移除查看、复制、移动、归档四个行内按钮，使案例内容成为列表视觉重点。

## 方案

- 每行只保留运行和删除，使用紧凑且固定间距的操作组，操作列保持内容宽度，避免按钮挤压或粘连。
- 案例名称使用真实详情链接，支持键盘访问；保留现有点击行进入详情的行为。复选框及操作按钮继续阻止行点击，避免误跳转。
- 保持案例名称、描述、回放方式、标签、版本、最近结果的现有信息层级；长案例名称和描述可换行，操作组不换行。窄屏通过表格容器横向滚动保证页面整体不溢出。
- 保留批量复制/移动、详情页复制/移动、模块操作和现有删除确认。移除行内归档入口，不增加替代入口；归档 API 保留。
- 更新 README 中关于列表行复制/移动入口的说明。

## 接口与兼容性

无接口、数据格式或迁移变更。运行、删除及详情导航保持既有行为；不会显示内部 UUID 或 session_id。

## 异常处理

沿用运行/删除现有错误提示与删除确认。空列表和无最近结果状态保持现有展示。

## 验收标准

1. 案例列表每行不再出现查看、复制、移动、归档按钮，运行和删除按钮可用。
2. 名称链接与行点击可进入详情，复选框和按钮不会意外触发导航。
3. 桌面及窄屏布局间距整齐，长名称不造成页面溢出；批量工具栏功能保持可用。
4. 类型检查、Web bundle、浏览器交互与布局检查、git diff --check 通过。此项为可逆的展示调整，不新增镜像实现的单元测试。
