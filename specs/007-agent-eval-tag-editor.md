# Agent Eval 标签新增与选择交互

## 1. 目标与当前行为

目前案例和模块标签均使用逗号分隔的文本框，用户必须记住已有标签并手工输入，容易拼写不同或重复。提供明确的新增、选择、移除操作，使常用标签可以复用。

已阅读 agent-eval 开发约定、内网 roadmap、已有界面 spec，以及标签表单、schema、Store 源码。沿用 spec 先确认后实施；不修改 SDK、模型调用或判分。

## 2. 界面方案

使用共用标签编辑组件替代逗号分隔文本框：

- **已选标签**：展示为可换行的胶囊，每个标签有移除按钮；无标签时提示“尚未添加标签”。移除只取消当前案例/模块的标注。
- **＋ 新增标签**：点击展开单个标签输入框，输入名称后点击“添加”或按 Enter 加入；“取消”/Escape 收起且不改变已选标签。输入框聚焦，空白名称显示就地提示。
- **选择已有标签**：点击展开组件内的选择面板，提供搜索框和可多选的复选框列表。点击即更新当前表单的标签，面板显示已选状态；“完成”收起。面板直接嵌入表单，避免模块编辑弹窗内再叠加弹窗。
- 新增与选择面板互斥，已选标签始终可见。新创建但未保存的标签可在当前组件中再次选择；保存成功后才能供其他案例/模块复用。
- 标签新增/取消选择都仅修改表单草稿，沿用原“保存”持久化；退出选择面板不会自动保存案例或模块。
- 选择按钮始终可用。没有已有标签时说明“暂无已有标签，点击新增标签创建”；搜索无匹配时提示无匹配，不隐式创建标签。
- 搜索不区分大小写；新增名称去除首尾空白，按精确名称去重，已选同名标签提示已添加。保留标签原有大小写，不全局合并或重命名。
- 新增一次加入一个标签，逗号作为名称的一部分，避免破坏 JSON 导入已有的含逗号标签。

## 3. 已有标签来源与范围

- 案例组件：当前有效模块下的所有有效案例的标签，跨模块汇总去重；包含当前案例的已选标签。
- 模块组件：所有有效模块的标签，包含当前模块的已选标签。
- 两类标签分别汇总，保持“案例标注”和“模块分类”的语义。只提供当前数据中使用的标签，不额外创建独立标签管理库。
- 打开编辑器时读取最新 /api/state；读取失败保留草稿/当前已有标签并显示可重试提示，不允许一次延迟响应覆盖用户已选项。模块弹窗可立即呈现，标签候选加载后更新。
- 候选标签为空或加载失败不影响新建标签和保存；归档数据不提供候选。列表显示、搜索和批量复制/移动中标签保留方式不变。

## 4. 数据、接口与兼容性

继续使用案例 definition.tags 与模块 tags 的 string[]，复用 /api/state 和现有保存接口，无数据库迁移或新增 API。标签直接从组件数组读取，不再通过拼接/拆分逗号往返。

已有标签的文本、顺序和含逗号名称正常回显，打开页面不自动修改存量数据；新标签追加，移除后重新选中追加至末尾。未改动的历史导入内容保持原样。

模块沿用现有最多 20 个标签限制，组件在新增/选择第 21 个时解释原因并拒绝，取消选择仍可用；案例不增加新数量/长度限制。服务端既有校验保持不变。

标签修改必须参与案例详情的未保存状态判断，继续阻止将未保存草稿直接复制/移动；保存后新副本与原案例标签一致。

首期不增加全局标签删除/重命名、颜色管理、列表批量打标签或新标签过滤器。

## 5. 异常与可访问性

- 输入/操作按钮使用明确标签及 type=button；Enter 添加标签不触发父表单保存，中文输入法组合期间 Enter 不提交。
- 空白或重复名称就地提示，焦点停留在输入框；添加成功清空输入，可连续添加。
- 移除按钮提供“移除标签 xxx”的可访问名称，搜索及选择项可通过键盘操作，错误使用 aria-live。
- 新增取消与选择完成将焦点返回触发按钮；删除标签后将焦点移至相邻标签或新增按钮。
- 长标签换行显示、移除按钮可见；375px 宽度下工具栏换行，选择列表在组件内滚动，页面不因标签面板产生整体横向溢出。
- 保存失败保留草稿；关闭模块弹窗或按原方式离开案例页沿用既有草稿生命周期，不引入新的导航拦截。

## 6. 验收标准

1. 案例新建/详情与模块新建/编辑均可点击新增、选择已有、取消选择及移除标签。
2. 案例候选跨模块复用，模块候选按模块汇总；空状态、搜索、已选状态、候选读取失败及重试正常。
3. 已有/新增/含逗号标签保存重载完整回显；不会因输入分隔符导致拆分或重复加入。
4. 模块最多 20 项有明确提示；案例标签修改可触发未保存修改提示，批量复制/移动完整保留标签。
5. Chromium 验证键盘交互、标签草稿、保存往返、模块弹窗、长标签、375px 布局。
6. 必要的标签状态/数据往返测试、TypeScript typecheck、Web bundle、git diff --check 通过。
