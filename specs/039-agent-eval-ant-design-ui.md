## 1. 目标与范围

按用户最新要求，agent-eval 正式 React Web 全部页面统一使用 Ant Design；覆盖案例/模块、新增编辑、导入、评测创建与列表/详情/报告、验证器及试验证、Judge 试评分、运行设置和公共弹窗。仅限 agent-eval，不迁移 VS Code 插件等其他应用。

本方案确认后取代 SPEC-035/036 中沿用旧版控件外观、Radix 原语的约束；继续保留已确认的信息结构和业务交互。SPEC-038 定义判定规则的具体修复，两份方案配套实施。

## 2. 当前行为

React 页面通过 components/ui.tsx 使用原生表单、旧 CSS，以及 Radix Dialog/Tabs；页面还存在原生表格、details 和自行绘制的状态/标签。仅替换基础按钮无法覆盖全站。已阅读 SPEC-035/036、内网 roadmap、应用清单和 UI/判定/评分源码。

## 3. 视觉与页面方案

- 全站浅色主题、中文 locale；通过 ConfigProvider 和 App 统一主色、间距、圆角、字体和反馈容器。默认蓝色主操作、浅灰背景、白色内容卡片，禁止每页自行覆盖组件颜色。
- 保留案例列表的模块侧栏与主列表；用 Layout/Menu、Table、Input.Search、Select、Tag、Space 和分页组件组织筛选及批量操作。保留 Shift/拖选/隐藏选择、稳定案例 ID 和已有加载方式，不改变服务端查询或分页语义。
- 案例新增/编辑保留左侧“输入 / 判定规则 / 配置” Tabs、右侧常驻执行结果与历史 Card；桌面双列，窄屏上下排列。避免把执行结果移回隐藏页签。
- 判定入口采用可键盘操作的 Ant Design Button 配合说明和状态 Tag；下方 Card 提供明确的移除操作。正文表单采用 Form.Item、Input/TextArea、Select、Checkbox/Switch、InputNumber；LLM 与规则操作遵循 SPEC-038。
- 评测创建使用 Steps；结果详情保留左侧案例、右侧内联结果工作台，使用 Card、Descriptions、Statistic、Collapse、Tabs 组织内容。报告和历史列表使用 Table；长日志/JSON 保留专用只读内容容器和局部滚动。
- 弹窗统一 Modal/Drawer，确认使用 Popconfirm 或 Modal；加载、空结果、失败使用 Spin/Skeleton、Empty、Alert/Result，轻量完成反馈使用 message。文件上传使用 Upload，保留现有后端接口、校验和预览流程。
- 列表不显示内部案例 ID/session_id；详情保留 session_id；Bad case 靠近案例名称。短错误不预留大块空白，长错误可展开。全局一致的保存/取消/危险操作层级。

## 4. 组件与依赖方案

新增 antd、@ant-design/icons；实施时选择支持当前 React 19 的稳定版本并锁定 bun.lock，验证构建兼容性。使用标准 Ant Design，不额外引入 ProComponents 或新状态管理框架。保留 React Router、TanStack Query 及现有草稿模型。

先将公共 UI 适配为 Ant Design，再迁移页面内直接使用的原生控件/表格/折叠区域，最后删除应用不再使用的 Radix 依赖与旧控件 CSS。保留必要的响应式布局、业务选择和日志样式；不得用旧 .btn/.form-control 等全局选择器覆盖 Ant Design 内部样式。

Form 用于字段布局、校验反馈，案例草稿仍为唯一数据来源，避免另建一份 Form 状态导致隐藏页签丢值。Tabs 保留必要表单内容/错误状态；Modal 明确任务和草稿生命周期；Select/Upload/Table 的事件与类型转换逐项适配，不把 DOM 事件接口直接套用。

浏览器资源本地构建，不使用 CDN/在线字体/远程图标。内网构建需同步新增包及其完整依赖和锁文件；本方案不包含 Windows 离线打包功能，也不将 Linux 构建当成 Windows 验证。

## 5. 接口、兼容性与异常处理

不修改 API、数据库、SDK、执行/判分合同与配置覆盖优先级。保留 hash 深链接、刷新/返回、复制/导入、冻结快照、取消/重试、试验证/试评分、未保存离开和 revision 冲突处理。

请求期间禁止重复提交；同一错误更新同一提示区域；请求失败可重试且保留输入。JSON 非法时跨页签仍阻止保存，不能因控件卸载被清除。执行中切页/关闭弹窗按原有任务语义处理，不隐式取消或重启。

4. 执行前后端类型检查、生产构建、必要的现有回归及 SPEC-038 交互测试，检查浏览器控制台和请求重复提交。测试适配以用户可见行为为依据，不绑定 Ant Design 内部 DOM。
