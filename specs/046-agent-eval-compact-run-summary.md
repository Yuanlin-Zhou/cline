# SPEC-046：紧凑批次摘要与导出菜单

状态：Implemented / 已实施
日期：2026-11-17
确认：用户批准简化后的原型，并要求“显示 token 数就行了，不需要显示费用，就按照这个实施”。

## 目标与现状
当前批次头部摘要展开统计、评分分组和进度条，占用过多空间。按已确认原型收为一个摘要区：执行结果与 LLM 评分两行及次要耗时/Token 信息。遵循 Ant Design、仅桌面要求。已阅读 AGENTS、内网 roadmap、SPEC-045、RunSummary 和 judgeSummary。

## 设计与实现
执行行展示已结束/总数、通过/失败/错误/无法判定/取消/待完成数量；次行展示累计耗时、Token、重试。不再展示进度条、费用或大数字卡。统计说明打开弹窗，保留回复检查/验收详细统计。
LLM 行展示已评分/应评分、已有分组均分；不合并不同评分器，最多预览两组，其余在查看详情弹窗中逐组展示。分组身份沿用服务端模型/来源版本/有效配置，未产出数值评分的情况明确显示暂无有效均分，并保留评分错误、信息不足、未评分和待评分汇总。Token 和耗时分别展示。无评分器显示未配置，不伪造分数。
导出 JSON/CSV/简报合并为菜单；保留停止、重试和重复评测行为。头部增加案例数。下方多轮报告保持 SPEC-045 实现，不采用原型示意图中合并其他状态的简化列。

## 接口与兼容
纯前端修改，不改评分规则、接口、持久化或导出数据；顶部摘要及其详情不展示费用，底层费用记录保留。耗时/Token 含全部尝试，状态按最新尝试统计。运行、取消、失败、长标题、多评分器和空结果保持明确展示。

## 验证计划
检查类型/构建与桌面浏览器：完成、运行中、未配置、多个/长评分器、评分异常，统计弹窗与导出菜单/重复评测；复核实际截图并记录。用户已授权实施，不重复请求批准。

## 实施与验证记录

- 顶部实现两行紧凑摘要，费用及进度条不再展示；单评分分组与已评分数量同行，多分组预览两组并可查看全部详情。无评分器、评分错误、信息不足、运行中分别展示；均分只来自有效数值分组。
- JSON/CSV/简报导出合为菜单，保留原 URL；统计说明打开弹窗，停止、重试及重复评测入口保留。下方多轮报告不改布局。
- 类型检查、Biome、Vite 生产构建通过。浏览器多评分器执行回归和新增紧凑摘要流程通过；验证统计说明、三类导出链接、重复评测弹窗、单/多/未配置评分器及运行/评分异常状态，且断言摘要及统计弹窗不含费用。
- 真实浏览器 1440px 单评分器、1280px 多个长评分器、详情和运行状态截图记录于 assets/046。页面布局与省略处理已检查，未出现水平溢出。测试先执行本地模拟模型生成批次，再用确定性 overview 响应覆盖异常/长内容状态；未调用外网模型。
