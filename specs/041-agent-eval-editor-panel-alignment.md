# SPEC-041：案例编辑页左右卡片对齐

状态：Implemented / 已实施
确认记录：用户于 2026-11-17 回复“继续实施”，批准本方案。
日期：2026-11-17

## 目标与当前行为

使右侧“执行结果”与左侧“基本信息”卡片顶部水平对齐。当前 page.tsx 的左侧 Tabs 在表单列内，右侧结果列从 Tabs 顶部开始，产生一行高度差。已阅读根目录/应用 AGENTS、内网 roadmap、SPEC-039 及编辑页布局代码。

## 方案

将页签导航与左右内容布局分行：导航独占上方布局行，左侧呈现页签内容，右侧呈现执行结果与历史记录；两侧第一张卡片处于同一网格行。保持导航视觉范围在左列，不使用固定像素 margin-top 模拟对齐。

保留输入/判定规则/配置切换、常驻结果、草稿和隐藏页签校验生命周期；页签切换不卸载执行结果、不触发重复请求。对齐卡片顶部，不强制两侧内容等高。

## 接口、兼容与异常

纯前端布局调整，无接口/数据变更。加载、运行、错误与长标题状态仍保持布局；继续使用 Ant Design，仅要求桌面端。

## 验收与步骤

确认后调整布局；桌面 1280、1440、1920 宽度检查卡片顶部对齐、长标题和浏览器缩放，并查看实际截图。回归页签切换、保存、执行结果更新和历史打开；类型检查与构建通过后补充记录并标记 Implemented。

## 实施与验证（2026-11-17）

使用 CSS Grid 将 Ant Tabs 导航放在第一行，左侧内容和右侧结果同处第二行，保留全部组件生命周期。真实浏览器最初发现 Ant Design 6 使用 ant-tabs-body-holder，已修正选择器；1280/1440/1920 宽度顶部坐标差小于 2 像素。已查看 [桌面对齐截图](assets/041/alignment-1440.png)，回归切页、保存、执行和历史查看通过。不要求手机端兼容。
