# SPEC-026 实测记录

日期：2026-10-26。代码基线 `59f3db8` 加本次 SPEC-026 工作区实现。所有数据均为独立生成的测试数据，未使用用户内网案例或模型凭据，未调用付费模型。

## 条件

- Bun 1.3.13，Node v24.3.0，INTEL(R) XEON(R) PLATINUM 8573C，可见 CPU 3 核，系统内存约 9.7 GiB。
- API：200 个约 10–200 KiB 案例，分布在 prompt、普通 history、原生函数调用 history，正文合计 20.51 MB；额外 0/5/25 批历史，每批 200 项，混合五种终态和部分大输出。每项预热一次，独立采样 30 次。
- 浏览器：151.0.7922.173，1440×1000，同机本地服务；复用诊断时的 200 案例、大于 5 批历史及重试数据。热导航预热一次，每项 30 次，另测 CPU 4 倍限速。
- 首次迁移和首次 JS 下载/编译不计入热导航；CLI API 基准禁用执行器，创建事务仍真实写入快照与摘要。

## 与诊断基线的关系

诊断时完整案例集/批次响应约 22 MB，重试后约 44 MB；现在正常页面不再传输这些静态正文，原完整接口和导出仍可按需访问。诊断浏览器单次打开约 1.5–2.4 秒、CPU 4 倍新建页约 4.2 秒。该诊断使用完整加载，并非本表相同的 30 次热导航分布，不能据此计算严格的百分比提速。

原始 API 与浏览器统计分别见 `performance-026-api.json`、`performance-026-browser.json`，复现命令见 `performance.md`。SQLite 必测；MongoDB 投影模拟和专用副本集用例已加入，当前未配置真实 MongoDB 测试连接，不能据此宣称已验证真实集群性能。
