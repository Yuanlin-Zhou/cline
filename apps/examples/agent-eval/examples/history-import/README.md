# 粘贴导入历史对话示例

打开案例的 **单轮函数调用 → 输入 → 历史对话 → 粘贴 JSON 导入**。

以下文件可直接复制进粘贴框（它们是对话记录，不是案例集）：

- `cline-messages.json`：Cline 原生消息，包含系统提示词、文本/工具内容块，以及不同的内部 ID 和 provider call_id。
- `openai-messages.json`：标准 Chat Completions 消息。
- `type-data-messages.json`：type/data 包装格式。
- `openai-reasoning-messages.json`：带 `reasoning_content` 的兼容服务记录，示例值为换行，可直接解析。

点击“解析并预览”，选择最后一条用户消息作为本轮输入，再点击“导入到案例”并保存。前文会成为历史，最后的问题要求模型生成 editor 调用；历史 read_files 不会执行。

`suite.json` 已将原生记录转换为一个完整案例，可在案例列表的导入入口使用。先将 modelId/baseUrl 改为实际模型配置；案例未绑定验证器，可以在判定规则中选择 Python editor 验证器。本轮只公布 editor，历史中保留 read_files，不执行任何工具。

完整原生会话如含待验证答案，可明确选择较早的用户消息作为本轮输入：此前作为历史，此后内容不导入。工具结果不属于新的用户问题，不能被选作本轮输入。

思考块默认阻止应用，需明确勾选“不发送思考块”；图片/媒体暂不支持，无法闭合的工具链也会报错。导入预览失败或取消均保留原草稿。

助手消息的 `reasoning_content` 接受字符串或 null。空值、空字符串和纯空白自动省略并提示；实际思考文本需要勾选“不发送思考块”后导入。该字段不会混入正文，也不作为请求字段发送或保存，原有工具调用/结果完整性检查仍然适用。
